# Scope

## In Scope
- Full storefront homepage with all sections
- Product catalog with filtering (category, price, room, color)
- Product detail pages with gallery and related products
- Session-based cart (add, remove, update qty)
- Checkout (guest checkout with order record)
- Newsletter signup
- Admin (Django admin for product/category management)

## Out of Scope (for now)
- User accounts / auth
- Payment gateway integration
- Order history / account dashboard
- Wishlist
- Product reviews submission (display only)
- Search (may add basic version)
- Multi-currency

## Phases
1. Scaffold — Django project, settings, layout, base templates
2. Models + migrations + seeders
3. Homepage — all sections
4. Catalog + product detail
5. Cart + checkout
6. Tests, polish, review
